# ADR-0016: Dear ImGui 설정 창

| 항목 | 내용 |
|---|---|
| 상태 | 승인 |
| 날짜 | 2026-10-13 |
| 관련 요구사항 | FR-06 (크기), FR-20 (애니메이션), FR-23 (모델 정보) |

## 맥락

설정을 바꾸려면 `deskpet.ini`를 직접 고쳐야 했습니다. 특히 모델 파일 안 애니메이션 27개 중 동작별 클립을 고르는 일(ADR-0015)은 이름을 정확히 적어야 해서 불편했습니다. 우클릭 메뉴(Win32 팝업)는 항목이 많은 목록이나 슬라이더·토글을 담기 어렵습니다.

조건: 배포 용량이 작아야 하고(지금 zip 약 0.7MB), 플랫폼 독립 모듈 규칙(R2)을 지켜야 하며, 캐릭터만 그리는 투명 오버레이(ADR-0011) 위에 그려야 합니다.

## 고려한 대안

| 대안 | 용량 | 장점 | 단점 |
|---|---|---|---|
| A. Win32 기본 대화상자 | 거의 0 | 가벼움 | 투박함, 리소스 스크립트·메시지 처리 코드가 많고 Windows 전용 |
| **B. Dear ImGui + 스타일** | +0.5 ~ 1MB | 가벼움, 위젯이 다 있음, 본체가 플랫폼 독립, 지금 D3D11 위에 바로 그림 | 기본 모양이 개발 도구 느낌 → 테마를 입혀야 함 |
| C. WebView2 (HTML) | +수 MB, 메모리 +100MB 이상 | 디자인 자유도 | 메모리, 런타임 의존 |
| D. Qt | +20 ~ 40MB | 기능 풍부 | 지금 규모에 비해 큼 |
| E. Unity uGUI (Mate Engine 방식) | 수백 MB | 편집기로 디자인 | 엔진 전체가 필요, 지금 구조와 맞지 않음 |

## 결정

B. Dear ImGui v1.92.9b(MIT)를 CMake FetchContent로 버전을 고정해 씁니다.

- **모듈**: 새 `ui` 모듈(플랫폼 독립)이 ImGui 컨텍스트를 소유하고 설정 창을 만듭니다. 앱 상태는 `SettingsState`로 받아 보여 주기만 하고, 사용자가 한 일은 `SettingsAction`으로 돌려줍니다. 적용과 저장은 `app`이 합니다(상태를 두 곳에서 맞출 일이 없음). ImGui 본체는 `deskpet_imgui`(경고 옵션 제외), D3D11 백엔드는 `deskpet_imgui_dx11`(Windows)로 따로 빌드합니다.
- **입력**: 오버레이 창은 클릭해도 포커스를 빼앗지 않는 창이라 키보드를 받지 않습니다. 그래서 마우스만 씁니다. Win32 백엔드(`imgui_impl_win32`) 대신 앱이 이미 받는 이벤트를 넣습니다: 위치는 매 프레임 커서 위치(클릭 통과 중에는 마우스 메시지가 오지 않음), 버튼은 포인터 이벤트, 휠은 새 `MouseWheelEvent`. 설정 창 위에서 누른 버튼은 뗄 때까지 캐릭터에 넘기지 않고, 그 동안 창은 클릭 통과를 끕니다.
- **그리기**: 렌더러의 오버레이 패스 맨 뒤 `ImGuiPass`가 공식 D3D11 백엔드로 프레임 텍스처에 그립니다. 백엔드 블렌드가 (SrcAlpha, InvSrcAlpha) + 알파 (One, InvSrcAlpha)라 결과가 premultiplied alpha라서 DirectComposition 합성과 맞습니다. 설정 창이 열려 있는 동안은 장면이 매 프레임 달라 Present를 생략하지 않고, 바뀐 곳만 처리하지 않고 전체를 처리합니다. 닫으면 지금처럼 쉽니다.
- **클릭 판정**: 창 바탕이 불투명이라 기존 픽셀 알파 판정(FR-04)으로 클릭을 받고, 알파 읽기가 2~3프레임 늦은 동안은 ImGui의 `WantCaptureMouse`로 보완합니다.
- **스타일**: 창 모서리 12px, 입력 칸 8px, 1px 옅은 테두리, 그림자 없음, 넉넉한 여백. 흰 바탕 + 회색 글자 + 분홍 강조색 하나. 어두운 테마는 Windows 앱 모드(`AppsUseLightTheme`)를 따름. 슬라이더·토글·탭은 그리기 함수로 직접 그림. 아이콘은 글꼴 파일 없이 선으로 그림(용량·라이선스 부담 없음). 한글은 시스템의 맑은 고딕(1.92부터 글리프를 필요할 때 만들어 한글 범위를 미리 굽지 않음). DPI 배율만큼 크기를 키움.
- **내용**: 탭 4개. 모델(이름·작가·라이선스·파일, 모델 열기), 동작(대기·걷기·끌려 다닐 때·공중의 클립: 기본 동작 + 모델 파일 안 애니메이션 + 설정 파일에서 지정한 다른 파일), 화면(크기, 커서 바라보기, 다른 창 위를 걷기, 대기 중 숨쉬기), 정보. 바꾼 값은 바로 적용하고 `deskpet.ini`에 바로 씀. 클립을 바꾸면 자세 경계 상자를 작업 스레드에서 다시 계산(큰 모델은 수백 ms).

## 결과

- 좋아지는 점: ini를 고치지 않고 모델·클립·크기·옵션을 바꿀 수 있음. 실행 파일이 약 0.5MB 커지는 정도. 설정 창 로직(배치, 닫기, 탭, 끌기, 마우스 가로채기)과 앱 쪽 처리(적용, 저장)를 Linux에서도 단위 테스트
- 감수하는 점: 키보드 입력이 없어 검색·직접 입력 칸은 없음(긴 목록은 휠로 스크롤). 반복 시작 시각(`*_loop_start`)은 아직 설정 창에 없음. 열려 있는 동안 매 프레임 화면 전체를 그림(닫으면 원래대로). 런타임 셰이더 컴파일에 `d3dcompiler_47.dll`(Windows 10 이상 기본 포함) 사용
- 우클릭 메뉴는 설정·위치 초기화·숨기기·종료만 남김. 버전·모델 정보·모델 열기·크기는 설정 창과 겹쳐 뺌
- 추가(2026-10-14): 반복 시작 시각, 항상 위, 걷기 끄기, 그래픽 탭(수직 동기화·안티에일리어싱·외곽선, 렌더러 `setOptions`로 재시작 없이 적용), 고급 탭(중력·점프 세기·걷기 속도·끌기 시작 거리, 기본값으로). 디버그 레이어·로그·창 크기는 개발용이거나 크기 슬라이더와 겹쳐 넣지 않음
- 변경(2026-10-14): 더블클릭은 점프 대신 "상호작용" — 동작 탭의 다섯 번째 슬롯(`[animation] interact_clip`)에 클립을 고르면 제자리에서 한 번 재생하고, 없으면 점프(기본 동작). 고급 탭에서 점프 세기는 뺌(점프는 기본 상호작용으로만 남음, `jump_speed` 키는 유지). 크기 최소 10%
- 후속 작업: 모션 파일 고르기(다른 파일)
