# ADR-0017: 외곽선 자동 선택과 화면 실루엣 외곽선

| 항목 | 내용 |
|---|---|
| 상태 | 승인 |
| 날짜 | 2026-10-16 |
| 관련 | ADR-0012 (MToon·선형 색공간), ADR-0011 (화면 전체 오버레이·3D 영역), ADR-0016 (설정 창) |

## 맥락

외곽선은 반전 헐(법선 방향으로 부풀린 메시를 앞면 컬링으로 다시 그림)로 그렸습니다. 굵기는 재질마다 모델이 정합니다(VRM MToon `outlineWidthFactor`, PMX 에지). 게임에서 내보낸 glTF는 이 정보가 없어서

- `model`(모델 지정)이면 외곽선이 아예 없고,
- `all`(모든 불투명 재질)이면 눈·입·눈썹처럼 얼굴 위에 붙인 얇은 판, 헤일로 같은 평평한 장식에도 껍데기가 그려져 얼굴에 선이 생기거나 장식 전체가 검게 칠해짐.

사용자가 모델마다 외곽선 방식을 골라야 하는 것도 불편합니다. 블루 아카이브 등 게임의 실제 처리 방식은 공개 자료가 없었고, 모델 파일에서는 재질이 부위별로 나뉘어 있고 일부 소품은 외곽선 전용 메시(`*_Outline`)를 따로 가진다는 단서만 있었습니다 (재질 단위로 외곽선을 켜고 끄는 구조로 추정).

## 고려한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| A. `all`에서 재질별로 빼기 (눈 본·이름·납작함) | 머리카락·옷의 안쪽 선이 남아 게임 느낌에 가까움 | 이름 규칙이 없는 모델은 놓칠 수 있음 |
| **B. 화면 실루엣 외곽선** | 모델 형식·재질 정보와 무관하게 같은 결과, 안쪽 선이 생기지 않음, 화면 단위 처리라 가벼움 | 안쪽 윤곽선(몸 앞의 팔 등)은 없음, 선 색은 하나 |
| C. 깊이·법선 엣지 검출 후처리 | 안쪽 선까지 화면 단위로 | 깊이·법선 버퍼가 따로 필요, 노이즈 조정이 어렵고 무거움 |

## 결정

**B를 추가하고, 기본값을 모델에 따라 고르는 `auto`로 합니다.** A는 `all`의 보조 규칙으로 넣습니다(후속 변경).

- **선택지** `[renderer] outline`: `auto`(기본) / `model` / `all` / `silhouette` / `off`
  - `auto`: 모델에 외곽선 정보(재질 굵기 > 0)가 하나라도 있으면 `model`, 없으면 `silhouette`. 앱이 정해서 렌더러에는 메시 외곽선 방식(`model`·`all`·`off`)과 실루엣 두께만 넘김
- **실루엣**: 3D 영역 텍스처를 프레임 텍스처로 옮기는 복사(`CopySubresourceRegion`)를 셰이더 패스(`SilhouettePass`)로 바꿔, 캐릭터 바깥(알파 < 1)에서 두께 안에 캐릭터 픽셀이 있으면 외곽선 색을 깔아 합침(premultiplied, `캐릭터 + (1 − 캐릭터 알파) × 선`). 둘레 16방향 × 고리 3개, 가장 바깥 고리는 절반만 세어 가장자리를 부드럽게
- **두께**: 상자 높이 × 0.45% × 외곽선 두께(%) — 캐릭터 크기·DPI에 비례 (기본 크기에서 약 1.5px)
- **색**: 살짝 밝은 보랏빛 회색 (sRGB 0.16, 0.13, 0.16) 하나

## 결과

- 좋아지는 점: 외곽선 정보가 없는 모델도 손대지 않고 깔끔한 외곽선. 눈·입·헤일로에 선이 생기지 않음. 반전 헐을 쓰지 않으므로 메시를 한 번 더 그리지 않음
- 감수하는 점: 실루엣 모드에서는 안쪽 윤곽선이 없음(원하면 `all` + 자동 제외). 기본값이 `model`에서 `auto`로 바뀌어, 외곽선 정보가 없는 모델은 업데이트 뒤 외곽선이 새로 생김(끄려면 `off`)
- 3D 영역 텍스처를 셰이더 리소스로도 만들어야 함 (`BIND_SHADER_RESOURCE`)
