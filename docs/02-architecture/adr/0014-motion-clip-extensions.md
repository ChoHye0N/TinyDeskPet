# ADR-0014: 모션 클립 확장 — 손가락·비휴머노이드 본·엉덩이 이동·반복 구간

| 항목 | 내용 |
|---|---|
| 상태 | 승인 |
| 날짜 | 2026-10-13 |
| 관련 요구사항 | FR-20 (애니메이션), ADR-0013 대체 |

## 맥락

ADR-0013은 휴머노이드 본(손가락 제외)의 **회전만** 재생하기로 했습니다. 실제 모션 파일로 써 보니 그 범위에서 잃는 것이 컸습니다.

| 빠진 것 | 예 |
|---|---|
| 손가락 | 클립에 있는 손가락 동작이 사라져 손이 펴진 채로 움직임 |
| 휴머노이드가 아닌 본 | 모델 전용 모션의 머플러·꼬리·귀·치마 키(한 클립에서 70 ~ 100°)가 모두 버려짐. SpringBone 물리만 남음 |
| 엉덩이 이동 | 집어 올릴 때 들리는 몸(+0.14m), 앉기·점프 높이가 사라짐 |
| 반복 구간 | 모든 클립을 처음부터 반복하므로 "집어 드는 동작 → 매달린 동작"처럼 시작 동작이 있는 클립은 시작 동작이 매번 다시 나옴. 또 누적 시간으로 재생해 동작이 시작될 때 클립 중간부터 나옴 |

다만 휴머노이드가 아닌 본은 모델마다 이름·개수·구조가 달라 VRM처럼 공통 이름이 없습니다. 모든 모델에 맞는 범용 방식이어야 하고, 그런 본이 없는 모델·모션도 깨지지 않아야 합니다.

## 고려한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| A. ADR-0013 유지 (휴머노이드 회전만, 나머지는 SpringBone) | 단순, 어떤 모델에도 같은 결과 | 위 손실이 그대로. 모델 전용 모션의 의도된 움직임(귀 쫑긋, 꼬리 살랑)을 재현할 수 없음 |
| B. 휴머노이드가 아닌 본을 위한 공통 이름 표 | 다른 모델끼리 일부 공유 | 이름 체계가 없어 표를 만들 수 없음. 틀린 매핑이 엉뚱한 본을 움직임 |
| **C. 휴머노이드는 지금처럼 리타깃하고, 그 밖의 본은 이름이 같을 때만 같은 방식(월드 델타 × 보정)으로 재생. 손가락은 휴머노이드에 추가, 엉덩이 이동은 키 비율로, 반복은 설정으로** | 공통 이름이 있는 부분은 모든 모델에서, 모델 전용 부분은 이름이 맞는 모델에서만 동작. 없으면 무시하므로 기존 모델·모션은 그대로 | 이름이 다른 같은 본(예: 다른 도구로 내보낸 같은 모델)은 맞추지 못함 |

## 결정

C. 재생 방식(월드 델타 Δ와 기본 자세 보정 C, ADR-0013)은 그대로 두고 범위를 넓힙니다.

- **손가락**: `HumanBone`에 VRM 1.0 손가락 30개를 넣습니다. VRM 0.x 엄지(proximal·intermediate)는 1.0의 한 칸 손 쪽(metacarpal·proximal)으로 옮겨 읽고, MMD(전각 숫자)·Mixamo·3ds Max Biped 이름도 매핑합니다. VMD 표준 뼈대에도 손가락을 넣습니다. 손가락 마디 방향도 기본 자세 보정에 씁니다.
- **휴머노이드가 아닌 본**: 로더(FBX, VRMA)가 부모와 다르게 움직이는 노드만 이름과 함께 저장합니다(부모를 그대로 따라가는 노드는 없어도 결과가 같음). 재생기는 대상 모델에서 이름이 같은 본에만 적용하고 없으면 버리며, 휴머노이드 트랙이 우선입니다. 보정 C는 부모의 것을 따릅니다. VMD는 휴머노이드가 아닌 본의 계층을 알 수 없어 제외합니다. SpringBone은 클립 자세를 기준으로 그 위에서 흔들립니다(기존 동작 그대로).
- **엉덩이 이동**: 로더가 엉덩이 위치 변화와 원본 엉덩이 높이를 원본 단위로 저장하고, 재생할 때 대상 엉덩이 높이 / 원본 엉덩이 높이를 곱합니다(같은 단위끼리 나누므로 VMD의 MMD 단위도 변환 없이 맞음). 수직은 그대로, 수평은 시작 위치와 시작 → 끝 이동(루트 모션)을 빼 흔들림만 남깁니다. 캐릭터를 화면에서 옮기는 것은 앱이기 때문입니다. 발 붙이기는 엉덩이 이동을 넣은 자세로 계산해 두 번 내리지 않고, 동작 전환 0.2초 동안 위치도 회전처럼 섞습니다.
- **반복 구간·재생 시각**: 클립은 동작이 시작될 때 처음부터 재생합니다. 처음 한 번 끝까지 재생한 뒤로는 `[animation] *_loop_start`(초)부터 끝까지 반복하고, 0이면 처음부터, 길이 이상이면 마지막 자세를 유지합니다.

## 결과

- 좋아지는 점: 같은 모델의 전용 모션(게임에서 추출한 모델 + 그 모델의 FBX 모션 등)이 손가락·머플러·꼬리·몸 높이까지 원본처럼 재생됨. 이름이 맞지 않거나 해당 본이 없는 모델은 지금과 같게 동작. 시작 동작이 있는 클립을 상태에 맞게 쓸 수 있음
- 감수하는 점: 이름 매칭은 정확히 같은 이름만 (접두사·대소문자 차이 무시 안 함). FBX 모션을 읽을 때 모든 노드의 델타를 한 번 계산하므로 노드가 많고 긴 클립은 로드가 조금 느려짐(그 뒤 메모리는 움직이는 본만). 엉덩이 높이 비율은 바닥이 y = 0이라고 가정
- 후속 작업: VRMA 표정 트랙, 걷기 클립 보폭과 이동 속도 맞추기, 휴머노이드가 아닌 본과 SpringBone이 겹칠 때 어느 쪽을 우선할지 선택
