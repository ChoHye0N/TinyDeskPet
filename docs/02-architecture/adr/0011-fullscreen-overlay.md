# ADR-0011: 화면 전체 오버레이 창 + 픽셀 단위 클릭 통과

| 항목 | 내용 |
|---|---|
| 상태 | 승인 |
| 날짜 | 2026-10-06 |
| 관련 요구사항 | FR-04, FR-17, NFR-PERF-01, NFR-PERF-02 |

## 맥락

지금까지는 캐릭터 크기만 한 창(320×340)이 캐릭터를 따라 움직였습니다. SpringBone(머리카락·옷 흔들림)을 넣자 착지·끌기 때 머리카락이 창 밖으로 나가 잘렸습니다. 창을 키우면 투명한 창 영역이 넓어져 그 부분의 클릭을 막고, 클릭 영역용 `SetWindowRgn`은 그리기까지 잘라냈습니다(학습 노트 #17).

## 고려한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| A. 작은 창 + 흔들림 여유 공간 | 변경이 작음 | 여유를 넘으면 여전히 잘림. 투명 영역이 클릭을 막음 |
| B. 작은 창 + 흔들림 범위 제한 | 단순 | 표현이 제한됨. 단독으로는 잘림을 막지 못함 |
| C. 레이어드 윈도우(`UpdateLayeredWindow`) | 알파 0 픽셀 클릭 통과가 자동 | 매 프레임 CPU 비트맵 복사 (ADR-0001에서 기각한 방식) |
| **D. 작업 영역 전체를 덮는 오버레이 + 커서 아래 알파로 클릭 통과** | 화면 안이면 잘리지 않음. 창을 매 프레임 옮기지 않음 | 렌더 타깃이 화면 크기. 클릭 판정을 직접 구현. 모니터 간 이동 처리 |

## 결정

D. 창은 캐릭터 발이 있는 모니터의 **작업 영역**(작업 표시줄 제외) 전체를 덮고, 캐릭터는 창 안의 "캐릭터 상자"로 움직입니다. 창은 `WS_EX_LAYERED | WS_EX_TRANSPARENT`로 기본이 클릭 통과이고, 매 프레임 커서 아래 픽셀의 알파가 0.1보다 크면 TRANSPARENT를 끕니다.

- 작업 영역인 이유: 모니터를 꽉 채운 항상 위 창은 Windows가 전체 화면 앱으로 보고 알림을 막을 수 있음
- 카메라는 예전처럼 상자에 맞추고, 투영 뒤에 "상자 → 오버레이" 2D 변환을 곱함 → 상자 밖으로 나간 머리카락도 그려짐
- DirectComposition 창(`WS_EX_NOREDIRECTIONBITMAP`)에 LAYERED를 함께 걸어도 그리기가 그대로인지 먼저 실험으로 확인 (화면 캡처 + `WindowFromPoint`)

## 결과

- 좋아지는 점: 흔들림·자세가 상자 밖으로 나가도 잘리지 않음. 캐릭터가 아닌 픽셀은 클릭이 정확히 아래 창으로 감. 매 프레임 `SetWindowPos`가 없어짐
- 감수하는 점: 렌더 타깃(프레임 텍스처·MSAA·깊이)이 화면 크기라 GPU·메모리 비용 증가. 측정(Debug, kei, 대기 동작, 내장 GPU): 작은 창 GPU 9.1% / 134MB → 오버레이 18.4% / 201MB. 대부분 화면 전체 MSAA 비용 (MSAA를 끄면 10.0% / 146MB) → 후속 최적화
- 감수하는 점: 클릭 판정이 2~3프레임 늦음. 모니터 경계에 걸친 동안은 두 작업 영역을 합친 크기로 창이 커짐 (그동안 렌더 타깃도 커짐)
- 최적화 (적용): 3D·MSAA를 캐릭터 주변 영역(상자 좌우 0.75배, 위로 상자 높이)만 그리고 프레임 텍스처의 그 자리에 복사 → GPU 18.4% → 14.2~14.7%, 메모리 201MB → 160MB (같은 조건, 작은 창 9.0% / 135MB)
- 최적화 2 (적용): 영역을 매 프레임 자세(흔들림 본 포함)에 맞춤 → 12.3% / 144MB. 바뀐 곳만 지우기(`ClearView`)·백버퍼 복사·`Present1` dirty rect → **10.8% / 144MB**

| 단계 (Debug, kei, 대기 동작, 내장 GPU) | GPU(3D) | 메모리 |
|---|---|---|
| 작은 창 (기준) | 9.0% | 135MB |
| 오버레이 | 18.4% | 201MB |
| + 3D 영역 (고정 여유) | 14.3% | 159MB |
| + 영역을 자세에 맞춤 | 12.3% | 144MB |
| + 바뀐 곳만 처리 | 10.8% | 144MB |

- 전체 화면 앱 (적용): 캐릭터가 있는 모니터에 전체 화면 앱(전용 전체 화면 D3D·프레젠테이션 모드, 또는 모니터를 꽉 채운 포그라운드 창)이 있으면 0.5초 안에 자동으로 숨기고 닫히면 다시 보임
- 모니터 경계 (적용): 몸 범위가 두 모니터에 걸치면 창을 두 작업 영역을 합친 사각형으로
